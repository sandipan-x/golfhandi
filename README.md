# GolfHandi

Calculate your golf handicap index from score differentials, and get your course handicap for any slope, rating and par. Free WHS-style calculator.

## Features
- WHS-style handicap index from your score differentials
- Course handicap calculator for any slope, rating, and par
- Score history log with improving/declining trend indicator
